# GitHub Repository Setup Guide for WordExpanderApp

Apne is project ko GitHub par daalne ke liye ye simple steps follow karein:

### Step 1: GitHub par nayi Repository banayein
1. [github.com](https://github.com) par jayein aur login karein.
2. Upar **"+"** button par click karke **"New repository"** select karein.
3. Repository name daalein: `WordExpanderApp`
4. Visibility: **Public** ya **Private** (jo aap chahein).
5. "Initialize with README" par check **mat lagayein** (kyunki hamare paas pehle se README hai).
6. **"Create repository"** par click karein.

---

### Step 2: Apne Terminal / CMD me ye commands run karein

Is folder ke andar terminal kholein:
`C:\Users\gopal\.gemini\antigravity\scratch\WordExpanderApp`

Aur ye commands run karein:

```bash
git init
git add .
git commit -m "Initial release: WordExpanderApp with Universal Multi-language & Keyboard Pop-up"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git push -u origin main
```
*(Apne GitHub ka real URL `YOUR_USERNAME/YOUR_REPOSITORY_NAME` ki jagah daal dein).*

---

### GitHub Desktop use karte hain to:
1. GitHub Desktop open karein.
2. **File -> Add Local Repository** par click karein.
3. Path select karein: `C:\Users\gopal\.gemini\antigravity\scratch\WordExpanderApp`
4. **"Publish repository"** button daba dein!
